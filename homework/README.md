# Домашнее задание №2
## Линейная и логистическая регрессия на PyTorch

### Цель работы
Закрепить навыки работы с PyTorch, изучить модификацию моделей машинного обучения, обработку различных датасетов, подбор гиперпараметров и создание новых признаков.

## Задание 1. Модификация существующих моделей (30 баллов)

### 1.1. Расширение линейной регрессии (15 баллов)
- Реализована линейная регрессия с использованием PyTorch.
- Добавлены L1- и L2-регуляризация для уменьшения переобучения.
- Реализован механизм Early Stopping для автоматической остановки обучения.
- Построены графики изменения функции потерь.
- Добавлено сохранение обученной модели.

### 1.2. Расширение логистической регрессии (15 баллов)
- Реализована многоклассовая классификация на датасете Iris.
- Используется функция потерь CrossEntropyLoss.
- Вычисляются метрики Precision, Recall, F1-score и ROC-AUC.
- Построена матрица ошибок Confusion Matrix.
- Реализовано сохранение модели.

### 2.1. Кастомный Dataset-класс (15 баллов)

- Реализована нормализация числовых данных.

### 2.2. Эксперименты с различными датасетами (15 баллов)
- Использован датасет Diabetes для линейной регрессии.
- Использован датасет Breast Cancer для бинарной классификации.
